📚 Receipt Tracker & Automated Expense Ingestion Workflow
📌 Overview
This is an automated Receipt Tracker workflow built with n8n. It allows users to upload receipt images via a form, extracts structured transaction details using AI, and automatically logs the parsed data into a database.

Receipt Submission & Vision AI Pipeline: Users upload a receipt image via an n8n Form. The workflow sends the binary image to Google Gemini to extract key invoice information (Merchant, Amount, Category, and Date) in structured JSON format.

Data Parsing & Database Logging: A JavaScript Code Node cleans and validates the extracted JSON output. The structured expense record is then automatically inserted into a PostgreSQL database table.

1. 📝 On Form Submission (n8n-nodes-base.formTrigger)
Purpose: Captures receipt image uploads directly from an n8n hosted web form.

Key Settings:

Form Title: image

Form Field: File input named Upload your image

2. 🧠 Analyze an Image (@n8n/n8n-nodes-langchain.googleGemini)
Purpose: Uses Google Gemini Vision capabilities to read the uploaded receipt image and extract structured expense details.

Key Settings:

Model: models/gemini-3.5-flash-lite

Input Type: binary (Upload_your_image)

Resource / Operation: image / analyze

Credentials: Google Gemini / PaLM API Account

3. ⚡ Code in JavaScript (n8n-nodes-base.code)
Purpose: Parses Gemini's raw output string, strips markdown formatting (e.g., ```json blocks), handles parsing errors gracefully with fallback defaults, and outputs clean JSON.

Key Settings:

Language: JavaScript (jsCode)

4. 🗄️ Insert Rows in a Table (n8n-nodes-base.postgres)
Purpose: Inserts the cleaned expense record directly into the specified PostgreSQL database table.

Key Settings:

Schema: public

Table: expenses

Column Mappings: merchant, amount, category, date

Credentials: Postgres Account

📝 System Prompts & Logic Setup
1. Gemini Vision Extraction Prompt:
"Read this receipt and extract the following in JSON format:
{"merchant": "store name", "amount": total_number, "category": "food/transport/shopping/bills/other", "date": "YYYY-MM-DD"}
Only output valid JSON, nothing else."

2. Data Fallback Logic (JavaScript Node):
JavaScript
const rawText = $input.item.json.content.parts[0].text;
const cleanText = rawText.replace(/```json|```/g, '').trim();

let data;
try {
  data = JSON.parse(cleanText);
} catch (e) {
  data = { merchant: 'Unknown', amount: 0, category: 'other', date: null };
}

return {
  json: {
    merchant: data.merchant,
    amount: data.amount,
    category: data.category,
    date: data.date
  }
};
📥 Step-by-Step Installation & Setup
Repository Setup:

Download the workflow.json file.

Open your n8n dashboard -> Click Import from File and upload workflow.json.

Database Table Setup:

Make sure your PostgreSQL database has an expenses table created with columns: merchant (text), amount (numeric), category (text), and date (timestamp/date).

Credentials Configuration:

Google Gemini Credentials: Attach your Google Gemini (PaLM) API Key to the Analyze an image node.

PostgreSQL Credentials: Connect your PostgreSQL Database credentials to the Insert rows in a table node.

Workflow Execution:

Activate the workflow and copy the public URL generated by the On form submission node.

Open the form, upload a receipt image, and submit to test automatic extraction and database entry.
