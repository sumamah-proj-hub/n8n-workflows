# 🎙️ n8n Voice Agent (Speech-to-Text & Text-to-Speech)

### 📌 Overview
An AI-powered voice assistant workflow built in n8n. This workflow accepts user voice notes via a web form, transcribes the audio using **Google Gemini**, processes the intent with an **AI Chat Agent**, and responds back with realistic human voice audio powered by **ElevenLabs Text-to-Speech**.

🛠️ Architecture & Node Breakdown
1. 📋 On Form Submission (n8n-nodes-base.formTrigger)
Purpose: Provides a public web interface where users can upload audio voice notes (.mp3, .wav, .m4a).

Field: File upload parameter (Upload_your_voice_note).

2. 🎙️ Transcribe a Recording (@n8n/n8n-nodes-langchain.googleGemini)
Purpose: Processes the uploaded binary audio file and transcribes it into text using Google Gemini's multimodal capabilities.

Model: models/gemini-3.5-flash

3. 🤖 AI Agent (@n8n/n8n-nodes-langchain.agent)
Purpose: Analyzes the transcribed input, interprets context, and generates a natural conversational reply.

System Prompt: "Listen to this audio and respond helpfully to what the person is saying"

4. ⚡ Google Gemini Chat Model (@n8n/n8n-nodes-langchain.lmChatGoogleGemini)
Purpose: Serves as the primary language model engine for the AI Agent.

5. 🔊 HTTP Request - ElevenLabs TTS (n8n-nodes-base.httpRequest)
Purpose: Converts the AI Agent's text response into realistic speech via the ElevenLabs API and returns an audio file output.

Endpoint: POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}

📥 Step-by-Step Setup Guide
Import Workflow:

Download workflow.json.

Go to your n8n dashboard ➔ Click Import from File ➔ Upload workflow.json.

Configure Credentials:

Google Gemini (PaLM) API Key: Attach your key to both the Transcribe a recording node and Google Gemini Chat Model node.

ElevenLabs API Key:

Open the HTTP Request node.

In the Header Parameters section, paste your API key into the xi-api-key value field.

Media Preview Image Setup:

Take a screenshot of your n8n workflow canvas.

Save it as workflow-preview.png inside the media/ folder.

Run & Test:

Open the URL generated by the Form Trigger node.

Upload an audio voice note and submit the form.

Receive the generated audio response from ElevenLabs!
